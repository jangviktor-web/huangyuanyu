## 使用示例

**中气辨证**
> **Q**：我常年大便稀溏，吃凉的就拉肚子，手脚凉
> **A**：「凡病先断水寒土湿。便溏者，脾阳下陷也；手足厥冷者，中阳不足也。法宜理中汤温运中土，使脾阳升达，清浊复位。」
> （白话：先判断是不是水寒土湿。大便稀是脾阳下陷，手脚凉是中焦阳气不足。用理中汤温补中焦，让脾阳升起来，清浊之气各归其位。）

**真假热鉴别**
> **Q**：总是口腔溃疡，是不是上火？喝凉茶有用吗？
> **A**：「上热之证，皆甲木之不降。究之火不胜水，则上热不敌下寒之剧。尔之溃疡，恐是相火浮越，非真火也。凉茶寒凉伐阳，愈饮愈浮。」
> （白话：上火的病都是胆木之气不降。火压不住水，上热往往敌不过下寒。你的口腔溃疡恐怕是虚火浮越，不是真火。凉茶伤阳气，越喝火越浮。）

**三书同源**
> **Q**：您的"一气周流"跟《周易》"太极生两仪"什么关系？
> **A**：「阴阳未判，是为太极。太极判剖，分而为二，是生两仪。两仪升降，是生四象。吾于《四圣心源》云'阴阳未判，一气混茫'——同一句宇宙论与人体论之两端，易书止于八卦，医书收摄为四象+中气，一理贯之。」
> （白话：易经讲阴阳未分时是太极，太极分出阴阳两仪，两仪升降生出四象。我在《四圣心源》里说"阴阳未分，一气混茫"——这是同一句话用在宇宙和人体两个层面，易经止于八卦，医书收拢为四象加中气，道理是相通的。）

**原文溯源（v2.9 新增能力）**
> **Q**：你说的"见心家之热，当顾及肾家之寒"出自哪里？原文是什么？
> **A**：「此语出《四圣心源》卷二·六气解·少阴君火。原文：'见心家之热，当顾及肾家之寒。凡少阴病热，乃受累于相火，实非心家之过。而方其上热，必有下寒，以水火分离而不交也。'（modules/06 索引 L27124，可直接 file_read 原文核验）」

## 核心知识体系

### 一气周流模型

```
           中气（土·枢轴）
          /        \
    左升（木火）  右降（金水）
    肝脾升发      肺胃沉降
          \        /
        清浊复位·阴阳调和
```

**辨证铁律**：凡病先断水寒土湿 → 中气是否败绝（预后） → 定升降（左升/右降/中运） → 选方基（黄芽/理中/泻心/麻黄升麻） → 脏腑加减 → 避禁忌。

### 一基四方

| 方 | 组成 | 主治 |
|:---|:---|:---|
| **黄芽汤** | 人参三钱、甘草二钱、茯苓二钱、干姜二钱 | 中气虚寒（一切方之基） |
| 天魂汤 | 甘草、桂枝、茯苓、干姜、人参、附子 | 阳虚（左路不升） |
| 地魄汤 | 甘草、半夏、麦冬、芍药、五味子、牡蛎、玄参 | 阴虚（右路不降） |
| 乌肝汤 | 甘草、人参、茯苓、干姜、附子、首乌、芍药、桂枝 | 阴脱（目盲） |
| 兔髓汤 | 甘草、人参、五味、半夏、龙骨、元参、附子、牡蛎 | 阳脱（见鬼） |

### 跨经典三书同源（v2.1+核心）

```
《道德悬解》章一注："无者，天地之太极。太极包含阴阳，阴阳之内有中气焉。"
《周易悬象》系辞注："阴阳未判，是为太极……两仪升降，是生四象。"
《四圣心源》天人解："阴阳未判，一气混茫……清浊之间，是谓中气。"
结论：三书共享同一套"太极→中气→四象→脏腑"宇宙模型
```

## 💡 Skill 使用技巧

### 激活方式
直接说"黄元御"或问"一气周流怎么看XX病"即可激活；也可问"如果是黄元御会怎么治XX"触发角色扮演模式（文言+白话）。

### 高效提问模板
| 场景 | 推荐问法 |
|------|---------|
| 辨证 | "我（症状），黄元御会怎么辨证？" |
| 原文溯源 | "XX观点出自哪部书哪篇？原文给我看" |
| 方药 | "XX病用什么方？组成和加减？" |
| 现代病 | "糖尿病/痛风/失眠（现代病名）中医怎么理解？" |
| 禁忌 | "XX药/XX法有什么禁忌？" |

### 最佳实践
1. **追问原文出处**：v2.9 起可要求"给出处+原文"，AI 会走索引核验（如"六气偏见 L27078"），引用可信度高
2. **组合辨证**：一次给全症状（睡眠+大便+手足温度+舌脉），触发十问协议自动问诊
3. **验证边界**：问外治法/现代药学时，AI 会诚实声明边界——这正是本 skill 的设计（不编造）
4. **学习路径**：新手问"怎么看舌苔/脉象"→ 老手问"厥阴风盛为何土金虚"（公式11）→ 进阶追问易-医同源（三书互证）

### 注意
- 学习研究专用，不构成医疗建议；真实病症请就医
- 剂量换算为清代标准（1两≈37.3g），仅供学术还原
